## Resumo dos Conceitos Praticados

Durante a aula foram praticados conceitos básicos da linguagem C, principalmente a declaração e utilização de variáveis, entrada e saída de dados e operações matemáticas. Também foram resolvidos exercícios introdutórios na plataforma Beecrowd, trabalhando com valores inteiros e reais, cálculos de soma, produto, área e médias ponderadas.

As principais estruturas utilizadas foram variáveis, `printf`, `scanf` e operadores matemáticos. Os exercícios contribuíram para reforçar a lógica de programação e a forma de receber dados do usuário, realizar os cálculos necessários e apresentar os resultados corretamente.
